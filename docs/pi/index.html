01 / INSTALL & CONFIGURE

Install the extension.
Connect a provider.

The same package works in Pi and OMP. Choose your host, then point pi-system-one at Jev or any compatible System One endpoint. 

pi install npm:pi-system-one
TypeSafe Jev
SYSTEM_ONE_BASE_URL=https://api.typesafe.ai SYSTEM_ONE_API_KEY=<TYPESAFE_API_KEY> SYSTEM_ONE_MODEL=jev-latest
Local / compatible endpoint
SYSTEM_ONE_BASE_URL=http://localhost:8009 SYSTEM_ONE_API_KEY=<optional-if-required> SYSTEM_ONE_MODEL=<optional-if-required>
Runtime configuration
SYSTEM_ONE_BASE_URL Required endpoint origin for the configured System One provider.
SYSTEM_ONE_API_KEY Optional. Set this when the provider requires authentication. You can also enter a session-only key through /so config.
SYSTEM_ONE_MODEL Optional. Set this when the provider requires an explicit model; otherwise leave it unset.
/so status Inspect the active endpoint, model, and credential source from the agent session.

02 / USE CASES

Use cases.

These are examples, not routing rules. The agent can call system_one when the work narrows to a bounded choice, yes/no judgment, or score. Let the normal agent gather evidence and run tools first; use /judge when you want that judgment path explicitly.
