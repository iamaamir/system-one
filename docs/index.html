01 / Architecture — System One

System One is
the abstraction.

Applications should depend on a capability, not a specific model. Jev and Reflex can sit behind the same bounded decision interface. Future backends can implement the same provider contract. system-one keeps application code independent from whichever provider performs the inference.

08 / Quickstart

Start in a few lines.

npm install system-one-core
import { SystemOne, HttpSystemOneProvider, choice } from "system-one-core";

const s1 = new SystemOne({
provider: new HttpSystemOneProvider({ baseUrl: "http://localhost:8008" }),
});

const result = await s1.evaluate({
state: "The export button crashes in Safari.",
questions: {
team: choice("Which team should investigate?", {
frontend: null,
backend: null,
}),
},
});

const team = result.answers.team;
console.log(team.choice, team.confidence, team.probabilities);
# LOCAL / REFLEX
pi install npm:pi-system-one
