Decisions, not strings.

System One models return typed answers with calibrated confidence — software can act on them. system-one is the tooling layer that brings those decisions into your TypeScript code and your Pi agent, against any backend. No routing. No tiers. No policy.

Two packages. One idea.

Dependency direction: pi-system-one → system-one-core. Nothing here depends on routing, model tiers, or policy engines.

system-one-core

TypeScript runtime. choice / noul / score builders with inferred answer types. One HttpSystemOneProvider for any /v1/systemone endpoint. Fail-closed validation. Deterministic mock for tests.

npm: system-one-core

pi-system-one

Pi extension. Registers the system_one tool: batched questions, env config, human-readable results with full probability distributions. Decisions inside the agent loop.

npm: pi-system-one

Three properties, held strictly.

Typed outputs

Choice, 0–1, 0–5. Answers are values your code can branch on; probabilities sum to 1. No parsing prose.

Calibrated confidence

Every answer carries confidence. Act above your threshold, escalate below it. Uncertainty becomes a control signal.

Provider-neutral

You choose the backend and model. The client asks and validates. Swap Jev for Reflex with a URL change.

FAQ

Short answers. The repo holds the long ones.

Is this part of TypeSafe?

No. Independent open source by @iamaamir, MIT licensed. It speaks the System One protocol, so it works with Jev — and anything else that does.

Does it route between models or pick tiers?

No. That is exactly what this project refuses to do. You pick the backend and model; the client asks, validates fail-closed, and returns.

Why not just use an LLM with JSON mode?

System One models are trained for calibrated decisions (RLCD), not human-pleasing chat (RLHF). The problem with chat-shaped intelligence is well put here. This project is the client side of that answer.

Which backends work?

Anything serving POST /v1/systemone. Tested live on TypeSafe Jev and local Reflex.

What does it cost?

The client is free (MIT). You pay only your backend.
