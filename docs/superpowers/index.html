01 / Install — Pi or OMP

Install once.
Configure a provider.

The same package works as a Pi extension and an OMP extension. Configure a System One endpoint, then the system_one tool becomes available to the agent. 

pi install npm:pi-system-one

Install pi-system-one as a Pi extension.

SYSTEM_ONE_BASE_URL=https://api.typesafe.ai SYSTEM_ONE_API_KEY=<your-api-key> SYSTEM_ONE_MODEL=jev-latest

Runtime configuration
SYSTEM_ONE_BASE_URL Required endpoint origin for the configured System One provider.
SYSTEM_ONE_MODEL Optional default model. Leave it unset when your provider supplies a default.
SYSTEM_ONE_API_KEY Optional API key. You can also enter a session-only key through /so config.
